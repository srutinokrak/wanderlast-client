# AGENTS.md

Course project ("Module 46 – Destination CRUD", app name: wanderlust). Currently a scaffold: `src/app/page.tsx` is empty and all real app code is yet to be written.

## Commands

- Dev server: `npm run dev` (http://localhost:3000). Use npm; `package-lock.json` is committed.
- Lint: `npm run lint` (script is bare `eslint` with flat config in `eslint.config.mjs`).
- Typecheck: `npx tsc --noEmit` — no script for this; run it to verify types (build also typechecks via `npm run build`).
- No tests exist yet.

## Stack quirks

- Next.js 16 + React 19, App Router, all code under `src/`. Path alias `@/*` → `src/*`.
- Tailwind v4: there is **no** `tailwind.config` file. Theme tokens are CSS variables mapped in `@theme inline` inside `src/app/globals.css`; edit colors/radii there. Dark mode is class-based on `.dark` (via `@custom-variant dark`).
- shadcn "base-nova" style, which is built on `@base-ui/react`, **not** Radix — component props/APIs may differ from classic shadcn docs. Use `cn()` from `@/lib/utils`.
- Everything in `src/components/ui/*` is generated by shadcn and pre-installed. Don't hand-edit those files; add new ones with `npx shadcn@latest add <component>` and put feature components in `src/components/`.
